{{- /* 统计正文字数（用于替代 Hugo 的 .ReadingTime / .WordCount）。 为什么不用内置值： Hugo 的 WordCount 按「空格」切词，中文没有空格，一整段汉字会被算成很少的 几个词。实测一篇约 1500 字的中文文章只有 WordCount=47， 除以默认 212 词/分钟再向上取整，ReadingTime 永远是 1 分钟。 这里的算法：汉字按字计，拉丁字母/数字按词计，二者相加。 - \p{Han} 覆盖常用汉字区（含扩展 A） - [A-Za-z0-9]+ 把连续的英文单词/数字当成一个词 用法：{{ partial "word-count.html" $page }} 返回整数 */ -}} {{- $p := . -}} {{- $plain := $p.Plain -}} {{- $cjk := len (findRE `\p{Han}` $plain) -}} {{- $latin := len (findRE `[A-Za-z0-9]+` $plain) -}} {{- return (add $cjk $latin) -}}
